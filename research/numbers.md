# The ledger

Every number Escapement publishes, generated by `make model` from `data/inputs.toml` and
`model/escapement.py`. Do not edit this file by hand. Documents link here as
`[text](numbers.md#id)` and `make docs` rewrites the link text to the value below.

Basis: **measured** (independent measurement), **vendor** (a claim by an interested party),
**spec** (fixed by a protocol rule), **design** (a choice this design makes), **assumption**
(a number we picked where no source fixes it), **derived** (computed from the others).
